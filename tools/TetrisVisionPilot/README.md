# Tetris Vision Pilot — C++ + 在线策略学习

Windows 原生 Win32 桌面工具：通过 Windows Graphics Capture（WGC）捕获指定游戏窗口，再对其中的 10×20 棋盘做网格颜色分析，识别当前四格方块，枚举候选落点，并用可训练策略选择动作。不依赖 Python 或 OpenCV；SCORE 优先使用从用户提供的 Tetris Online `num_anm_02.IPL/.SPR` 还原的原生数字模板，匹配不可靠时回退到静态链接的 Tesseract OCR。Tesseract 英文模型随包附带。

## 捕获兼容性

- WGC HWND 捕获接口最低要求 Windows 10 1903（内部版本 18362）；Windows 10 22H2（19045）直接支持，不需要 Windows 11。当前目标环境为 Windows 10 22H2 build 19045.2846。
- WGC 不会把遮挡在目标窗口前方的其他桌面窗口合成进画面，但目标窗口最小化、隐藏或被系统/应用限制捕获时仍可能无法得到有效帧。

## 核心能力

- 枚举可见窗口，并优先使用 Windows Graphics Capture（WGC）直接采集所选 HWND；其他窗口覆盖在上方时，不会混入所选游戏窗口的图像。分别框选棋盘与 NEXT 预览列，调节颜色差阈值并预览识别结果。
- WGC 不捕获最小化窗口；若 WGC 初始化或运行失败，程序会明确记录并回退到桌面 BitBlt 截图，此回退模式仍会受到遮挡影响。
- 识别 I/O/T/S/Z/J/L 七种标准方块；针对 Tetris Online 的颜色调色板补充识别。
- 支持该游戏出生区被顶部边界裁切时，根据方块颜色与三格可见形状恢复被隐藏的第四格。
- 模拟旋转、左右移动和 Space 硬降；UI 可调整按键保持、连续按键间隔和硬降后等待时间。每局开局会在安全出生区尝试左右单格短按校准，先复位方块再开始决策；无法可靠复位时会停止，不会继续硬降。校准动作不进入训练样本。
- F8 全局停止；游戏窗口失去前台焦点时中止输入。
- 读取 NEXT 列中的预览方块；模拟智能模式使用有限宽度 Beam Search 和在线策略学习。另有独立“纯数学穷举”模式：完整枚举当前方块及最多两个 NEXT 方块的所有合法放置，不使用 Beam Search、随机探索、经验记忆或模型权重，也不产生训练样本。
- 每次落块保存基于整条候选路径的策略梯度样本；以 120ms 间隔持续采集 SCORE，先匹配游戏原生 0–9 数字图像模板，无法可靠分割或匹配时才回退到 Tesseract；随后检测 GAME OVER。结算界面出现前若分数已清零，会保留最后可信分数，并可自动点击 Again 重开。
- 模型、参数、日志、CSV 训练记录和追加式经验档案保存在 EXE 同目录。

## 策略模型与基础示范

界面模式选择默认是“模拟智能（学习）”；需要确定性对照时切换为“纯数学穷举”。穷举模式使用固定的字典序目标：优先保证能放置的方块数量，其次增加消行数，再依次减少空洞、最高高度、总高度、起伏、井和行/列边界变化；相同结果时优先减少旋转与横移按键数。它只对当前可见序列（当前方块 + 最多两个 NEXT）和上述目标保证最优，不宣称对未知后续方块的整局全局最优。

当前不是 CNN，而是可解释的 8 维线性策略。候选落点特征包括总高度、空洞、表面起伏、最高列、井、行边界、列边界和预计消行数。

首次初始化或重置模型时，程序会用规则教师构造一批基础示范：18 种典型地形（空棋盘、平面、阶梯、凹槽、交替高低、近完成行等）及空洞变体，对 I/O/T/S/Z/J/L 七种方块枚举合法落点，并形成“较好落点优于较差落点”的配对偏好样本。程序用这些合成样本预训练 8 个权重；UI 会显示“基础示范样本”数量。这不是外部高手录像，而是可以检查和解释的规则生成示范。这属于正常的比较式学习，不等于非必要惩罚，也不模拟痛苦或压力体验。这属于正常的比较式学习，不等于非必要惩罚，也不模拟痛苦或压力体验。

实时运行中，模型仍会使用 Softmax、ε 探索与 NEXT Beam Search。默认探索率调整为 5%，温度 0.40，避免已有基本策略后仍大量随机尝试。每个硬降保存一条样本；成绩高于移动平均基准时才执行正向更新，低分只记录数据，不进行反向惩罚式权重更新。由于仍是整局分数分配给当局动作的简化方法，长期改善需要多局数据，且不能保证每局都提高。

超过历史基准的整局会将当局每个动作的棋盘特征、方块、NEXT 前缀和落点写入 `TetrisVisionPilot-experiences.csv`，并进入成功经验检索库；低分局也会写入档案供分析，但不会成为正向示范。相似局面中匹配的历史落点只获得小幅偏好加成，不会锁死动作选择。

旧版模型文件会保留历史局数、平均分和最高分，但因缺少基础示范版本标记，首次升级时会换用新的预训练初始权重；之后再正常保存和学习。

## GitHub Actions 构建

本项目位于仓库的 `tools/TetrisVisionPilot/`，仓库根目录的 `.github/workflows/tetris-vision-pilot.yml` 负责 Windows x64 构建。成功后会上传名为 `TetrisVisionPilot-Windows-x64` 的 artifact，包含 EXE 与说明文档。

本机编译要求 Windows 10/11、Visual Studio 2022 Build Tools（Desktop development with C++）和 CMake。双击 `build.bat` 即可构建并启动。

## 使用步骤

1. 以窗口化或无边框模式启动俄罗斯方块游戏；不要最小化游戏窗口。程序会优先使用 WGC 捕获指定窗口，独占全屏或特定反作弊/保护内容仍可能限制捕获。
2. 启动 EXE，刷新并选择 Tetris Online 游戏窗口。
3. 框选棋盘内部完整的 10×20 区域（截图约 X=121–304、Y=100–465；实际运行时以窗口位置为准），不包含 NEXT、HOLD 或边框。顶部出生格即使被游戏裁切，也会尝试用颜色和可见三格推断。
4. 点击“框选 NEXT 区域”，只框住右侧 NEXT 预览卡片列，不要包含 NEXT 标题、箭头或边框。默认读取 6 格。
5. 点击“测试识别”，确认当前方块、占用格和 NEXT 队列都识别正确。
6. 在一局正在进行的游戏中点击“框选 SCORE 数字”，只框住实际分数数字，再点击“测试 SCORE OCR”，确认识别结果正确。
7. 首次自动运行前，先手动完成一局；进入 Game Over 画面后点击“框选 Again 按钮”，只框住按钮内部，然后手动点击游戏里的 Again 回到新一局。自动重开默认开启，因此必须先完成这一步校准；也可以取消复选框关闭自动重开。
8. 设置“前瞻 NEXT”深度（默认 4）、学习率、探索率和温度，再点击“开始自动落块”。程序会持续缓存 SCORE；确认 GAME OVER 后冻结快照、自动提交本局样本并保存 CSV。启用自动重开时，点击位置取自已框选的 Again 区域，启动前会验证 SCORE 和 Again 都在所选游戏窗口内部，点击后还会确认新方块出现。移动游戏窗口或改变缩放后，需要重新框选 SCORE 与 Again。
9. 观察权重变化，或用 Excel 打开 `TetrisVisionPilot-training.csv`。

## 当前限制

- 当前方块与 NEXT 使用颜色分割与格子连通分析；SCORE 优先使用从游戏 `num_anm_02` 资源解码的原生数字模板，低置信度时回退 Tesseract；GAME OVER 文本仍使用 Tesseract。SCORE 数字区域需在 UI 单独框选并通过测试。模板匹配阈值和实际窗口缩放仍需用户在游戏内验证。WGC 输出为目标窗口的图像帧，窗口最小化时不可捕获；WGC 不可用时才回退到桌面 BitBlt。
- 假设标准 10×20 棋盘、颜色对比明显、Up 顺时针旋转、Space 硬降。
- 多步规划使用有限宽度 Beam Search：每个当前落点保留最多 5 条后续路径，并按特征权重打分；它是近似搜索，不是穷举所有未来组合。
- 当前尚未实现 HOLD 自动使用、各游戏完整 SRS 踢墙、垃圾行或特殊模式。
- 仅根据当前棋盘和当前方块作决策，不会自动改写 C++ 源码。
- 运行前请确认目标游戏允许模拟输入。操作时不要切换焦点；F8 可紧急停止。
