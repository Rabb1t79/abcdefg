# Tetris Vision Pilot — C++ + 在线策略学习

Windows 原生 Win32 桌面工具：对屏幕中的 10×20 棋盘做网格颜色分析，识别当前四格方块，枚举候选落点，并用可训练策略选择动作。不依赖 Python 或 OpenCV；SCORE OCR 使用静态链接的 Tesseract，并随包附带英文模型数据。

## 核心能力

- 枚举可见窗口、分别框选棋盘与 NEXT 预览列、调节颜色差阈值和预览识别结果。
- 识别 I/O/T/S/Z/J/L 七种标准方块；针对 Tetris Online 的颜色调色板补充识别。
- 支持该游戏出生区被顶部边界裁切时，根据方块颜色与三格可见形状恢复被隐藏的第四格。
- 模拟旋转、左右移动和 Space 硬降；UI 可调整按键保持、连续按键间隔和硬降后等待时间。
- F8 全局停止；游戏窗口失去前台焦点时中止输入。
- 读取 NEXT 列中的预览方块；每个当前落点继续模拟后续方块，使用有限宽度 Beam Search 搜索多步路径。
- 每次落块保存基于整条候选路径的策略梯度样本；游戏中持续缓存 SCORE，GAME OVER 时自动结算，并可自动点击 Again 重开。
- 模型、参数、日志和 CSV 训练记录保存在 EXE 同目录。

## 策略模型与基础示范

当前不是 CNN，而是可解释的 8 维线性策略。候选落点特征包括总高度、空洞、表面起伏、最高列、井、行边界、列边界和预计消行数。

首次初始化或重置模型时，程序会用规则教师构造一批基础示范：18 种典型地形（空棋盘、平面、阶梯、凹槽、交替高低、近完成行等）及空洞变体，对 I/O/T/S/Z/J/L 七种方块枚举合法落点，并形成“较好落点优于较差落点”的配对偏好样本。程序用这些合成样本预训练 8 个权重；UI 会显示“基础示范样本”数量。这不是外部高手录像，而是可以检查和解释的规则生成示范。

实时运行中，模型仍会使用 Softmax、ε 探索与 NEXT Beam Search。默认探索率调整为 5%，温度 0.40，避免已有基本策略后仍大量随机尝试。每个硬降保存一条样本；成绩高于移动平均基准时才执行正向更新，低分只记录数据，不进行反向惩罚式权重更新。由于仍是整局分数分配给当局动作的简化方法，长期改善需要多局数据，且不能保证每局都提高。

旧版模型文件会保留历史局数、平均分和最高分，但因缺少基础示范版本标记，首次升级时会换用新的预训练初始权重；之后再正常保存和学习。

## GitHub Actions 构建

本项目位于仓库的 `tools/TetrisVisionPilot/`，仓库根目录的 `.github/workflows/tetris-vision-pilot.yml` 负责 Windows x64 构建。成功后会上传名为 `TetrisVisionPilot-Windows-x64` 的 artifact，包含 EXE 与说明文档。

本机编译要求 Windows 10/11、Visual Studio 2022 Build Tools（Desktop development with C++）和 CMake。双击 `build.bat` 即可构建并启动。

## 使用步骤

1. 以窗口化或无边框模式启动俄罗斯方块游戏；独占全屏可能无法通过 GDI 截图。
2. 启动 EXE，刷新并选择 Tetris Online 游戏窗口。
3. 框选棋盘内部完整的 10×20 区域（截图约 X=121–304、Y=100–465；实际运行时以窗口位置为准），不包含 NEXT、HOLD 或边框。顶部出生格即使被游戏裁切，也会尝试用颜色和可见三格推断。
4. 点击“框选 NEXT 区域”，只框住右侧 NEXT 预览卡片列，不要包含 NEXT 标题、箭头或边框。默认读取 6 格。
5. 点击“测试识别”，确认当前方块、占用格和 NEXT 队列都识别正确。
6. 设置“前瞻 NEXT”深度（默认 4）、学习率、探索率和温度，再点击“开始自动落块”。
7. 点击“框选 SCORE 数字”只框住游戏中 SCORE 的数字部分，再点击“测试 SCORE OCR”。自动控制时程序会持续缓存分数；确认 GAME OVER 后冻结快照、提交本局样本并保存 CSV。自动重开默认开启，点击 Again 前会验证弹窗已消失；可以取消复选框关闭自动重开。
8. 观察权重变化，或用 Excel 打开 `TetrisVisionPilot-training.csv`。

## 当前限制

- 当前方块与 NEXT 使用颜色分割与格子连通分析；SCORE 与 GAME OVER 使用 Tesseract 英文 OCR。SCORE 数字区域需在 UI 单独框选并通过测试。OCR 仍需在实际游戏窗口大小、缩放和主题下实测。
- 假设标准 10×20 棋盘、颜色对比明显、Up 顺时针旋转、Space 硬降。
- 多步规划使用有限宽度 Beam Search：每个当前落点保留最多 5 条后续路径，并按特征权重打分；它是近似搜索，不是穷举所有未来组合。
- 当前尚未实现 HOLD 自动使用、各游戏完整 SRS 踢墙、垃圾行或特殊模式。
- 仅根据当前棋盘和当前方块作决策，不会自动改写 C++ 源码。
- 运行前请确认目标游戏允许模拟输入。操作时不要切换焦点；F8 可紧急停止。
