# 在线强化学习入门

这份说明对应程序中的 `PolicyTrainer` 与 `ChoosePolicyAction`。

## 1. 状态与动作

视觉模块先把画面转换成 10×20 占用矩阵，并识别当前方块。程序枚举合法旋转与列位置，模拟每个落点，并从 NEXT 预览框读取后续方块类型。每个候选落点被表示为 8 维特征：

`φ = [总高度, 空洞, 起伏, 最高列, 井, 行边界, 列边界, 消行]`

模型保存权重 `w`，候选动作偏好为：

`z(a) = w · φ(s,a) / 温度`

## 2. Softmax 与探索

`π(a|s) = exp(z(a)) / Σ exp(z(b))`

Softmax 把偏好转为动作概率。ε 探索会以一定概率从所有候选落点中随机选择，避免模型过早只尝试一种策略：

`P(a) = (1 - ε) × π(a|s) + ε / 候选动作数`

温度越低，概率越集中；温度越高，动作分布越平缓。

## 3. NEXT 多步规划

对当前方块的每个合法首步落点，程序独立保留最多 5 条高分后续路径，并依次尝试 NEXT 队列中的方块。搜索深度由 UI 的“前瞻 NEXT”控制。当前路径评分是当前板面特征加上未来板面特征的折扣和（折扣系数 0.82）。Softmax 在首步路径评分之间分配概率；探索和训练梯度也使用整条首步路径的累计特征。

这是一种近似搜索：不穷举全部后续组合，暂时也不考虑 HOLD、SRS 踢墙或特殊规则。

## 4. 成绩如何训练模型

每次成功执行一个硬降后，程序缓存该状态下所选动作的策略梯度样本。运行时 OCR 持续读取 SCORE 数字，并在 GAME OVER 时冻结最后一个可信值作为本局最终分数。程序使用历史移动平均作为基准：

`优势 A = clamp((本局分数 - 历史平均分) / max(2500, 历史平均分 × 0.35), -2, 2)`

- `A > 0`：本局高于基准，沿本局样本平均梯度方向做正向强化。
- `A ≤ 0`：本局成绩与差值照常记录，但权重保持不变；不执行反向更新或负向惩罚。
- 首局只建立基准，不更新权重。

更新近似为：

`若 A > 0：w ← clip(w + 学习率 × A × 本局平均梯度 × 2)；若 A ≤ 0：w 保持不变。`

权重限制在 [-20, 20]。提交成绩后会保存模型和 CSV 快照。

## 5. 基础示范样本

模型首次初始化或重置时，会从规则生成的典型棋盘样本中预训练。样本覆盖空棋盘、平面、阶梯、凹槽、左右高低变化、近完成行和空洞变体；每种地形都对 I/O/T/S/Z/J/L 生成候选落点，再按 8 个特征的规则教师分数形成成对偏好样本。预训练只学习“更好的落点应该排在更差落点之前”，没有使用惩罚或负向奖励。此类样本是合成规则示范，不是实际玩家录像。

旧版 model.ini 没有 bootstrap 版本标记。升级时保留历史成绩统计，但改用当前示范库预训练权重；之后生成的模型会保存示范样本数量和新权重。

## 6. 如何做可重复实验

建议固定游戏、规则和计分方式，先连续记录 10 局以上。每轮只修改一个参数：

| 参数 | 含义 | 建议起点 |
|---|---|---|
| 学习率 | 每次更新幅度 | 0.03–0.08 |
| 探索率 | 随机尝试的动作比例 | 5% |
| 温度 | Softmax 概率平滑程度 | 0.40 |

比较 CSV 中的平均分、最高分和各个权重，不要只根据单局分数判断模型是否进步。

## 7. 这是不是大型神经网络？

不是。当前模型只有 8 个可解释参数，没有隐藏层，也不会自我修改源代码。它用于展示策略分布、探索、基础示范和正向策略更新。整局最终分数作为本局动作的共同反馈，信用分配比较粗糙。后续可以改进逐步消行反馈、HOLD 规划和更完整的 SRS 规则，再与神经网络策略做公平对照。
