# Tetris Vision Pilot Benchmark — CPU / GPU 硬件穷举对照

这是独立于原训练版的 Windows 原生 C++ 测试程序，目录为 `tools/TetrisVisionPilotBenchmark/`。它保留原项目的窗口捕获、棋盘/NEXT 识别、Ghost 落点反馈、离散按键校准、SCORE 识别、GAME OVER 检测和 Again 自动重开，但不执行在线策略训练，也不写入旧版本模型文件。

## 两种计算后端

- **CPU 多核穷举**：使用当前 CPU 的逻辑处理器创建并行工作线程，拆分首层候选，并对后续 NEXT 路径执行同一套规则搜索。
- **GPU Direct3D 11 计算**：通过硬件 D3D11 Compute Shader 扩展搜索树并在 GPU 上完成最终候选归约。必须创建真实硬件适配器；若设备不可用、驱动不支持或着色器初始化失败，程序会明确停止，不会暗中回退到 CPU 或 WARP。

两种模式使用相同的 10×20 棋盘几何规则和字典序目标：先尽可能放置更多块；其后优先当前第一步立即消除两行及以上，再比较前瞻内累计两行及以上消除事件与行数，之后比较空洞、高度、起伏、井、边界变化与按键动作数。前瞻范围是当前方块加最多两个 NEXT。它对当前识别出的序列与目标函数求解，不代表未知未来方块的整局全局最优。

GPU 首次创建设备、缓冲区和着色器的初始化耗时单独记录；稳态搜索时间不含这次冷启动。CPU 与 GPU 的计数含义可能不同：CPU 记录实际遍历的合法节点，GPU 记录本次扩展阶段的候选槽位规模；比较时应优先看搜索耗时、端到端时间和实际清行结果，不要把两个计数直接视为相同工作量。

## 识别与自动控制

程序继续使用 Windows Graphics Capture 捕获指定游戏窗口；识别当前方块、固定格和 NEXT 预览，读取 Ghost 轮廓用于落点核验。窗口移动后，已保存的棋盘/NEXT/SCORE 区域会按窗口客户区坐标重新定位。WGC 不支持最小化窗口；若初始化失败则尝试桌面截图，桌面回退可能受到其他窗口遮挡。

输入采用**离散独立点按**：每格一次 key-down/key-up，不通过长按方向键触发游戏连发。默认目标是按下约 1 ms、释放间隔 0 ms，并在安全出生区做 1–4 ms 点按校准。这里的 1 ms 是发送脉冲的目标时长，不等于游戏必定在 1 ms 内响应。Windows 调度、SendInput、游戏帧循环、WGC 帧采集和输入焦点都会增加端到端延迟；程序会分别记录搜索耗时、输入链路耗时和从规划到下一块确认出生的端到端耗时。**不存在可保证的 0 ms 输入，也不承诺每个局面都能在 1 秒内完成两行消除。** 如果当前可见方块序列或棋盘没有合适的两行消除方案，求解器不会凭空制造机会。

每局会在程序目录写入独立的 `TetrisVisionPilotBenchmark.log`、`TetrisVisionPilotBenchmark-marathon-memory-v2.csv` 和 Wall Kick 实测记录。每次硬降后，程序等待预测的 NEXT 方块在出生区被识别，再提交预测的锁定棋盘。记忆档案按事件追加：形状令牌（如 `T2`、`<L3`）、独立实例编号、旋转、落点、消行、性能数据、完整棋盘快照，以及 200 个格子的实例归属 ID。消行时占用格和归属 ID 同步压缩，因此一个方块即使被消行切成碎片，残留格仍保留原实例编号。程序重启时可选择恢复上一会话或开始新一局；恢复时若出现档案中不存在的新格，会停止而不是猜测。

记忆能力的边界：程序只能继承此前已记录的格子。第一次启用本版本时，如果棋盘里已经有无法识别的透明砖块，这些隐藏格不能仅靠截图还原。恢复上一会话时必须确认游戏仍处于同一局；若当前棋盘已是新局，应选择“否”建立新会话。初始已有但可识别的格会以“未知来源”归属 ID 0 保存，之后由程序放置的每个方块会拥有独立实例 ID。

## 使用

1. 在 Windows 10/11 上以窗口化或无边框方式启动 Tetris Online，不能最小化。
2. 运行 `TetrisVisionPilotBenchmark.exe`，选择游戏窗口。
3. 分别框选棋盘和 NEXT 区域，点击“测试识别”确认当前块、固定格和 NEXT 队列。
4. 框选 SCORE 数字并测试。需要自动重开时，在 Game Over 画面框选 Again 按钮；也可以关闭自动重开。
5. 选择 CPU 或 GPU 模式，然后开始自动落块。GPU 模式会先显示实际适配器名称与冷启动初始化时间。
6. 测试完成后使用“打开性能日志”和“打开马拉松记忆”查看结果。CSV 可用 Excel 打开。

F8 或“停止”可中止自动操作；游戏失去前台焦点时程序会停止发送按键。运行前请确认游戏允许模拟输入。

## 构建与发布

仓库工作流 `.github/workflows/tetris-cpu-gpu-benchmark.yml` 在 Windows Server 2022 runner 上安装静态 Tesseract 依赖，使用 MSVC/CMake 构建 x64，并将 EXE、D3D11 着色器、OCR 模型和文档打包为 `TetrisVisionPilotBenchmark-Windows-x64` artifact。原稳定训练版仍位于 `tools/TetrisVisionPilot/`，本测试版不覆盖它。
